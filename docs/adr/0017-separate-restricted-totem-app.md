# Separate restricted application for the academy kiosk

The **Totem da Academia** will be a separate client from the manager, with its own restricted **Modo Totem** rather than the full **Responsável da Academia** session. A responsible grants access primarily through a short one-time **Pareamento do Totem** code valid for 10 minutes (with QR Code as an optional convenience); the backend issues a persistent, revocable scoped session tied to the academy and authorizing responsible, so the shared tablet never needs the responsible's password or full operational permissions.

This boundary was chosen to keep the kiosk experience independent from the manager's technologies and UI while reducing the impact of an unattended shared device. The scoped authorization survives refreshes and device restarts until explicitly revoked, avoiding daily setup while preserving a clear kill switch. The kiosk may have its own frontend and deployment, but it shares the App do Sensei API and data source rather than duplicating domain or backend rules; QR payloads still point to the canonical student portal URL, not the kiosk origin. The trade-off is an additional pairing lifecycle and a dedicated client/API surface instead of reusing the manager wholesale.
