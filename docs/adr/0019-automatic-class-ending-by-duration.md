# Classes end automatically by their configured duration

An **Aula** will transition from `active` to `ended` automatically on the server when its real start time plus its configured duration is reached; the manager may still end it early, while the **Totem da Academia** will not expose a manual end action. An occurrence scheduled for the current day may be started early or late by explicit user confirmation, and the actual start time remains authoritative for duration and QR validity. After automatic ending, the kiosk returns to the day's occurrences and never starts the next class automatically. This keeps a class started from the restricted kiosk from remaining active indefinitely and makes the calculated QR validity window authoritative across clients, at the cost of requiring reliable server time and a scheduled or catch-up expiration mechanism.
